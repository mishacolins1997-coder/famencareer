# Career & Fame — расширение для SillyTavern

Установка: скопировать папку `career-fame` в
`SillyTavern/public/scripts/extensions/third-party/` (или `data/<user>/extensions/`) и перезапустить ST.
Настройки: Extensions → Career & Fame.

Режимы модели:
- Текущее подключение — ничего настраивать не нужно.
- Connection Profile — нужен установленный расширение Connection Manager; ключ берётся из профиля.
- Свой endpoint — любой OpenAI-совместимый роутер; ключ необязателен. Если сервер не разрешает CORS, запрос из браузера не пройдёт.
